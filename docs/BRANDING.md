# Mera-Sukoon24 brand integration — v0.4.1

The supplied square artwork is used without a generative redesign. The original colours, lettering and background are retained.

| Asset | Use |
| --- | --- |
| `branding/mera-sukoon24-original.png` | Unmodified supplied source and welcome-page brand image |
| `icons/icon-192.png` | PWA icon and visible app-header image |
| `icons/icon-512.png` | High-resolution PWA icon |
| `icons/icon-maskable-512.png` | Complete artwork padded into the maskable safe area |
| `icons/apple-touch-icon.png` | 180×180 Apple home-screen icon |
| `icons/favicon-16.png`, `icons/favicon-32.png` | Browser favicons |
| `favicon.ico` | Multi-resolution legacy browser favicon |

The manifest, document metadata and offline shell reference these assets. The previous geometric SVG has been removed from the current tree. No native Android or iOS project exists in this repository; no native launcher resources or APK were changed.

Small sizes retain the full artwork, including lettering, so fine lettering will be less legible at favicon size. The source file remains available for a future symbol-only variant if requested. The artwork's wording is branding; the app remains a self-help tool and does not claim clinical credentials or guaranteed mental relief.

For an existing installation, finish or export unsaved entries, close all Sukoon tabs and reopen after the update is downloaded. Some operating systems cache home-screen icons separately and may require removing and re-adding the shortcut. Real-device launcher refresh has not been tested.
